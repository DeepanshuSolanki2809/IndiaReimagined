# IndiaReimagined
A vision grounded in reality. Inspired by possibility. Built for everyone.

> **Designing the Future of India**

India Reimagined is an open-source, research-driven website that explores evidence-based ideas, global best practices, and long-term opportunities for India's future development. A place where India's hardest problems are turned into understandable, testable, and continuously improvable system designs.

The project is designed to be:

- 🌏 Informative
- 📊 Data-driven
- 🎯 Non-political
- ♿ Accessible
- 📱 Responsive
- 🚀 Fast
- 💙 Open Source

---

# Vision

India Reimagined aims to become a high-quality educational resource that helps citizens, students, researchers, planners, and policymakers explore India's future through facts, visualizations, and thoughtful ideas.

The website distinguishes between:

- Current facts
- Global inspiration
- Future possibilities

Every statistic should reference a trusted source.

# Getting Started

Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/IndiaReimagined.git
```

Open the project.

```bash
cd IndiaReimagined
```

Launch `index.html` in your browser.

No build tools are required.

# Coding Standards

- Semantic HTML
- Mobile-first CSS
- Vanilla JavaScript
- Meaningful file names
- No inline styles unless absolutely necessary
- No unnecessary dependencies

---

# Accessibility

The project aims to follow WCAG 2.1 AA guidelines.

Including:

- Keyboard navigation
- High color contrast
- Alt text
- Semantic HTML
- Reduced motion support
